# Coolify Portal MVP Design Gate

## Context

The approved request introduces a user-facing portal with authentication, authorization, persistence, and infrastructure control boundaries. The handoff records a completed planning phase, and the owner subsequently instructed the implementation to proceed from the approved plan.

The Universal Design Gate applies because the request is substantive and changes application behavior. No E1-E5 exemption fits this work.

## Ruling

Assign `docs/designs/2026-09-24-coolify-portal-mvp-design.md` as the design of record. Require `docs/adr/0001-coolify-portal-mvp-architecture.md` because the design introduces database schemas and security boundaries.

Proceed with implementation from the approved design and ADR. Keep the external Coolify smoke test gated on real environment values.

## Conditions

- Keep the prototype single-tenant and private.
- Keep Coolify as the deployment engine.
- Preserve server-only access to Coolify credentials.
- Require Security Monitor review before a pull request touches authentication, secrets, or infrastructure.
- Register the design document with status `implemented` after the local quality gates pass.
